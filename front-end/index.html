Visão Geral e Contexto do Desafio

Origem: NASA Space Apps Challenge

O Problema Global: A Crise da Agricultura diante da Volatilidade Climática

Agricultores ao redor de todo o mundo estão sob pressão extrema e sem precedentes: variações bruscas de temperatura, irregularidade severa no regime de chuvas, secas prolongadas, eventos climáticos extremos e uma acelerada degradação da fertilidade e microbiologia do solo.

Historicamente, o planejamento de rotação de culturas dependia da intuição e da memória histórica de safras anteriores. Contudo, as alterações climáticas romperam esses ciclos previsíveis, tornando decisões como "o que plantar em seguida?", "quando semear?" e "como proteger o solo na entressafra?" em apostas de alto risco financeiro e ambiental.

Escassez Hídrica & Chuvas Tardias

Períodos secos cada vez mais longos que coincidem com estágios críticos da floração e enchimento de grãos, arruinando colheitas inteiras.

Erosão e Exaustão do Solo

Monoculturas contínuas esgotam os nutrientes da rizosfera, aumentam pragas endêmicas e reduzem a capacidade do solo de reter umidade.

O "Data Gap" (Abismo entre o Espaço e o Produtor Rural)

A NASA possui a frota de observação da Terra mais avançada da humanidade, gerando terabytes diários de índices de umidade do solo, anomalias térmicas e radiação solar. No entanto:

Capítulo 02

O Desafio Oficial: Field Shift: Adapting Farms with NASA Data

Diretrizes da NASA
Declaração Central do Desafio (Challenge Statement)
"Criar uma aplicação interativa ou ferramenta de suporte à decisão que una as observações da Terra da NASA, dados locais de características do solo, atributos específicos das culturas e as prioridades individuais do agricultor, permitindo que os produtores explorem, simulem e avaliem estratégias inteligentes de rotação de culturas para adaptar suas fazendas às mudanças climáticas."
1

Integração de Múltiplos Dados

Combinar medições orbitais (temperatura, chuva, umidade do solo) com características locais do solo (textura, matéria orgânica) e exigências de cada cultura.

2

Prioridades Personalizadas

A solução não pode ser "tamanho único". O produtor deve poder escolher priorizar: economia de água, regeneração de nitrogênio ou rendimento financeiro imediato.

3

Simulador Comparativo

Permitir que o agricultor teste diferentes cenários de rotação (ex: Safra convencional vs Safra adaptada com adubo verde) e compare os impactos gerados.

4

Linguagem Clara & Transparência

Exibir recomendações claras, explicar as premissas adotadas e esclarecer as limitações dos dados (não é uma bola de cristal, mas sim suporte à decisão).

Capítulo 03

Fontes de Dados & APIs da NASA para o Frontend

Integração Técnica

Para viabilizar o projeto no Frontend sem depender de arquiteturas de backend pesadas e complexas no hackathon, selecionamos as fontes oficiais de dados abertos da NASA que fornecem APIs REST públicas e gratuitas ou camadas de mapa abertas.

API Primária (Pronta para Frontend)
REST JSON • Sem API Key

NASA POWER (Agroclimatology API)

O Prediction of Worldwide Energy Resources fornece séries temporais agrometeorológicas completas para qualquer coordenada do planeta com resolução diária.

// Parâmetros fundamentais:
• T2M_MAX / T2M_MIN: Temp. máx/mín a 2 metros (°C)
• PRECTOTCORR: Precipitação diária corrigida (mm)
• RH2M: Umidade relativa do ar (%)
• ALLSKY_SFC_SW_DWN: Radiação solar global incidente
• WS2M: Velocidade do vento a 2 metros (m/s)
Aplicação no S.O.L.O:

Cálculo do balanço hídrico, histórico de chuvas do talhão e previsão agrometeorológica para semeadura.

Umidade de Solo
Radar & Radiômetro

NASA SMAP (Soil Moisture Active Passive)

Mapeia a umidade volumétrica nas camadas superficiais (0-5 cm) e na zona radicular (root zone, até 100 cm). Fundamental para prever secas antes que as folhas comecem a secar.

// Indicadores monitorados:
• Surface Soil Moisture (cm³/cm³)
• Root-Zone Soil Moisture (Capacidade de campo)
• Soil Moisture Anomaly (Desvio do padrão histórico)
Aplicação no S.O.L.O:

Alerta de estresse hídrico na raiz e indicador de viabilidade de germinação para a próxima cultura.

Estresse Térmico & Transpiração
ISS Radiometer

NASA ECOSTRESS (na Estação Espacial)

Mede a temperatura da copa vegetal em altíssima resolução espacial (~70m). Revela exatamente quando as plantas estão "suando" e sob estresse hídrico severo.

// Principais saídas:
• Evapotranspiração Real (ETa)
• Evaporative Stress Index (ESI)
• Water Use Efficiency (WUE)
Aplicação no S.O.L.O:

Detecção precoce de superaquecimento do dossel da lavoura antes de danos permanentes.

Chuva Global & Índices Vegetativos
Constelação Satélite

GPM IMERG & MODIS (NDVI/EVI)

O Global Precipitation Measurement fornece mapas de precipitação quase em tempo real, enquanto o sensor MODIS oferece o histórico de verdor e vigor (NDVI).

// Utilização direta:
• NDVI (Normalized Difference Vegetation Index)
• Precipitação acumulada nos últimos 30, 60 e 90 dias
Aplicação no S.O.L.O:

Comparação da saúde da biomassa safra a safra para comprovar a regeneração da terra.

Next.js API Route Handler (TypeScript) para Cache e Proxy da NASA:

src/app/api/nasa/power/route.ts 
// src/app/api/nasa/power/route.ts (Next.js App Router)
import { NextResponse } from 'next/server';

export async function GET(request: Request) {
  const { searchParams } = new URL(request.url);
  const lat = searchParams.get('lat') || '-8.83';
  const lon = searchParams.get('lon') || '13.23';
  const start = searchParams.get('start') || '20250101';
  const end = searchParams.get('end') || '20251231';

  const params = 'T2M,T2M_MAX,T2M_MIN,PRECTOTCORR,RH2M,ALLSKY_SFC_SW_DWN';
  const nasaUrl = `https://power.larc.nasa.gov/api/temporal/daily/point?parameters=${params}&community=AG&longitude=${lon}&latitude=${lat}&start=${start}&end=${end}&format=JSON`;

  const res = await fetch(nasaUrl, {
    next: { revalidate: 86400 } // Cache de 24h na borda Next.js para economizar requisições
  });

  const data = await res.json();
  return NextResponse.json(data);
}
